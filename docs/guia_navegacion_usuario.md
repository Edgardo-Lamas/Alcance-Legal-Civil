# Guía de Navegación del Usuario

Bienvenido a la consola de **Alcance Legal**. Esta guía le ayudará a entender las opciones disponibles y el flujo de trabajo optimizado para su práctica profesional.

## 1. Concepto de la Consola
A diferencia de otras herramientas de IA, esta consola no presenta un chat abierto. Se estructura en **flujos de trabajo específicos** para garantizar precisión jurídica y orden metodológico.

## 2. Opciones de Navegación

### 1. Panel de Control (Consola)
Vista general de su actividad reciente y acceso rápido a las capacidades principales.

### 2. Analizar Caso
**¿Cuándo usarlo?** Al recibir un cliente nuevo o evaluar un caso desde cero.
- **Entrada**: Relato de los hechos y pretensiones.
- **Resultado**: Un informe detallado con índice de viabilidad, análisis de elementos y detección de riesgos (ej. prescripción).

### 3. Auditar Estrategia
**¿Cuándo usarlo?** Cuando ya tiene una teoría del caso y quiere una "segunda opinión" de un asociado senior.
- **Objetivo**: Detectar inconsistencias lógicas, supuestos no validados o debilidades probatorias.

### 4. Redactar Escrito
**¿Cuándo usarlo?** Para generar una primera estructura técnica de un acto procesal.
- **Importante**: Los borradores generados requieren revisión profesional obligatoria. El sistema señala qué secciones deben ser completadas por usted.

## 3. Flujo Jurídico Recomendado
Para obtener el máximo beneficio del sistema, siga este orden:
1. **Analice** el caso para validar si es viable según la doctrina y jurisprudencia.
2. Defina su **Estrategia** y sométala a auditoría para pulir riesgos.
3. Utilice el módulo de **Redacción** para plasmar la estrategia validada en un borrador técnico.

## 4. Banderas de Alerta
Durante su navegación, verá indicadores de color:
- 🔴 **Riesgo Crítico**: Requiere atención inmediata (ej. plazos).
- 🟡 **Advertencia**: Elemento a profundizar o validar.
- 🟢 **Consistencia**: Fundamentación sólida detectada.
